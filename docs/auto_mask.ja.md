# 自動マスクの仕組み

[English](auto_mask.en.md) · [README](../README.ja.md#自動マスク試験的)

SnapRef Region Probe と SnapRef Region Auto Mask が、人物ごとの領域をどう推定しているかと、重みの学習方法の説明です。使い方は README を見てください。

## 全体の流れ

1. **記録**（Region Probe）: 生成中の各 step で、モデルの各層（Anima は28ブロック）の cross-attention から、画像の各トークンがプロンプト中の `person_1` / `person_2` の語にどれだけ注目したかを記録します。指定した step・層では、self-attention の出力（トークン特徴）を PCA で64次元に縮めて記録します。生成結果は変えません。
2. **スコア**（Auto Mask）: 層ごとの注目マップを正規化し、「人物1 − 人物2」の差を特徴にします。学習済みの層ごとの重みで足し合わせ、トークンごとのスコアにします（正なら人物1）。
3. **部品分け**: 指定した step のトークン特徴（ブロック 8・12・16）に位置を足し、k-means で192個の部品に分けます。部品ごとにスコアを合計し、符号で人物を決めます。トークン単位のまだらを、まとまった部品単位にそろえるためです。
4. **画素への仕上げ**: 推定に使う画像を SLIC で約800個の superpixel に分け、superpixel ごとに多数決で人物を決めます。輪郭を画像の境目に合わせるためです。
5. 結果は `mask_1`（人物1）と `mask_2`（人物2）です。すべての画素がどちらかに割り振られ、背景も含みます。

推定は GPU で1回約0.1秒です（k-means は格子状の初期値と固定回数、SLIC は torch 実装）。CPU 版（skimage）も残してあり、精度は同等です。

## 3段構成にしている理由

- 下書き（SnapRef なし、4 step）だけのマスクは、SnapRef をかけると構図が変わってずれます。
- そこで、下書きのマスクで SnapRef ありの 0〜8 step を描き、その生成自身の記録と、その時点の完成予想（`denoised_output`）から推定し直します。本番の 30 step と構図がそろいます。
- 推定し直しの段は30 step スケジュールの一部（SplitSigmas）なので、SnapRef Region Mask の `ref_start` は区間の中の割合に換算します（0.1 × 30 step → 8 step の区間では 0.3125）。

## 層ごとの重み（`weights/*.json`）

重みファイルは、下書きの step 数 k（8・12・16・20・30）ごとに次を持ちます。

| 項目 | 内容 |
|---|---|
| `windows` | スコアに使う step の窓（0..k 全体、後ろ1/3、または両方） |
| `weights` | 窓ごと・層ごとの重みと切片（リッジ回帰の係数） |
| `feature_step` | 部品分けに使うトークン特徴の step |
| `loso` | 場面を1つずつ外して学習したときの誤差（下記） |

実行時の step 数がちょうど一致しないときは、それ以下で最大の k の重みを使います。

### 同梱の `hakushi_anima_gt_v1`

- **データ**: hakushiMixAnima v1.0、30 step（er_sde / simple、CFG 4）、SnapRef なしで生成した29枚。人物語は `1girl | girl` と `1man | man` です。
- **正解マスク**: 画素ごとに 0＝人物1、1＝人物2、255＝その他。推定結果を手で直し、目で確認して作りました。
- **評価**: 人物の画素のうち、相手の人物に割り振られた割合（取り違え率）です。背景への漏れは数えません。同じ場面（同じプロンプト）の画像はまとめて外して学習し、外した場面で測ります。
- **結果**（平均）: k=8 で7.6%、k=12 で4.1%、k=20 で3.4%、k=30 で3.6%。
- 学習は SnapRef なしの生成で行いました。実際に推定する推定し直しの段は SnapRef ありですが、同じ重みで推定できています。

### 学習のしかた

`tools/fit_auto_mask_weights.py` で学習します。

1. **生成と記録**: 2人の場面を、SnapRef なしで30 step 生成します。Region Probe に `auto_mask` と `dump_path` を指定し、層ごとの注目とトークン特徴を `.npz` に保存します。同じプロンプトを seed 違いで2〜3枚ずつ作ると、場面ごとの評価ができます。
2. **正解マスク**: 生成画像と同じ大きさの8ビット PNG を作ります（0＝人物1、1＝人物2、255＝その他）。Auto Mask の結果を下書きにして、取り違えを手で直すと早くできます。
3. **一覧**: データフォルダに `index.json` を置きます。

```json
[
  {"id": "bench-01", "scene": "bench", "image": "images/bench-01.png", "dump": "dumps/bench-01.npz", "gt": "gt/bench-01.png"}
]
```

4. **学習**:

```sh
python tools/fit_auto_mask_weights.py <データフォルダ> --out weights/my_weights.json --description "..."
```

窓の種類と部品分けの step の組み合わせを、場面を1つずつ外して評価し、誤差が最小のものを選びます。そのうえで全データで学習し直し、`--out` に書き出します。評価の一覧は `my_weights.report.json` に出ます。`weights/` に置くと、Region Probe の `auto_mask` と Auto Mask の `weights` で選べるようになります（ComfyUI の再起動が必要）。

## 参照への類似度（`source`）

人物語への注目だけでは、プロンプトで片方の人物にだけ付けた小物（ベレー帽、うさ耳フードなど）が、相手側や背景側に入りがちです。人物語の注目が体に集まり、小物には弱いためです。

- SnapRef Region Mask は、参照ごとに自己注意を計算しています。Region Probe の `ref_affinity` をオンにすると、その計算から、領域の制限をかける前の「参照ごとの注目の強さ」（log-sum-exp）を受け取り、画素ごとに「参照1の割合」を記録します。SnapRef がもともと計算している値なので、時間はほぼかかりません。
- `source = reference` は、この割合だけで分けます。ただし、画像全体が片方の参照に偏りやすく、両方の参照に共通する特徴（白いブラウス、顔立ち）は手がかりにならないので、単独では外れます。
- `source = both` は、体を人物語で決め、類似度で補正します。
  1. 人物語のスコアで、仮の人物1・人物2の領域を作ります。
  2. 仮の領域それぞれで「参照1の割合」の平均を出し、2つの中点を0、平均を ±1 に合わせます（±3で頭打ち）。画像全体の偏りがこれで打ち消されます。
  3. 人物語のスコアをばらつきで割ってそろえ、補正した類似度に `ref_weight` を掛けて足します。
  - 人物語で確信が強い所（顔・体）は変わらず、人物語では弱く外れていて類似度がはっきり一方の参照を指す所（帽子・フード）だけがひっくり返ります。
  - `ref_weight` は 0.5〜1 が釣り合っていました。2以上にすると、相手の人物の一部まで取り込み始めます。

## 制約

- 学習した人物語は `1girl` / `1man` だけです。女の子2人では、位置の語（`girl on the left` / `girl on the right`）で推定できました。髪や服の語を人物語にすると、その語の部分しか拾えず、体の大半が相手側になります。
- 小物の語を人物語に `|` で足すのは逆効果です。足した語の注目が一点に集まり、体の分を押しのけます。小物は `source = both` で拾います。
- 2人までです。3人に広げるには、人物ごとのスコアと3択の多数決への作り直しと、3人の場面での学習が必要です。
- マスクが制限するのは参照を読む範囲だけです。プロンプトの語や、画像トークンどうしの自己注意は、両方の人物に届きます。
